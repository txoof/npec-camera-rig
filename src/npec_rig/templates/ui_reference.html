Figure and readout

Macros ui.figure and ui.readout. A figure is a plot that opens full screen when tapped (lightbox.js); it starts hidden, and the page shows it once its image has loaded. A readout is the numbers beside it; the page writes each value into its id. plot-split puts the two side by side, one column on a phone.

{{ ui.figure("ex-figure", "Example plot") }} {{ ui.readout("ex-readout", [("ex-readout-tags", "Tags"), ("ex-readout-slope", "Fit slope")]) }}

Stepper

Macro ui.stepper, made to work by ui.bindStepper(). In place of a slider: whole steps, or tap the value to type one.

{{ ui.stepper("ex-stepper", "Analogue gain", "1.25", "x", 1, 16, 0.25, 2) }}

With tight=true: smaller buttons with the label beside them, for rows under an image. ui.bindStepper(el, onChange, {stops}) steps through a list of values, here gain in 1/3 stops. ui.setDisabled() greys a stepper out. A button with aria-pressed is a toggle: pressed shows a ring and a tick.

{{ ui.stepper("ex-stepper-tight", "Gain", "1.25", "x", 1, 16, 1, 2, tight=true) }} {{ ui.button("Auto", id="ex-toggle", icon_name="ok", attrs={"aria-pressed": "false"}) }}
