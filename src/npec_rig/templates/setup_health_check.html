On-demand checks, outside the linear Calibration wizard — for whenever you want to check on the rig without redoing setup from the start.

Tripwire check

Compares the four corner tags right now against the baseline saved by the last calibration that had "Set as current baseline" checked — the roll/knock acceptance test. Needs a saved calibration first (Calibration); running this immediately after that calibration is expected to read no change.

Honesty plot

PLAN.md's M2 acceptance test: place a known target at each of several positions, read its pixel position off the calibration frame below, measure the actual error with a ruler, and add a row below. "Claimed" is looked up automatically from the live calibration. Points on the diagonal are honest; scattered off it at random is fine; drifting with position is the signal that opens the intrinsics evidence gate (CLAUDE.md) — that judgement is yours to make from where they land.
