Calibration history

Every calibration ever run and saved, most recent first. A calibration's validity depends on the camera/rig's physical state, not when it was captured — if nothing has moved since an older one was taken, it is exactly as valid today as it was then.

Making one active is not a substitute for running a full calibration. It reactivates an old measurement; it does not re-verify that the physical setup still matches it.

To see diagnostics (heatmaps, rank plots) for the active calibration, go to Calibration → Step 5 → "Load diagnostics for the active calibration."
