Honesty plot

PLAN.md's M2 acceptance test: place a known target at each of several positions, read its pixel position off the calibration frame above, measure the actual error with a ruler, and add a row below. "Claimed" is looked up automatically from the live calibration. Points on the diagonal are honest; scattered off it at random is fine; drifting with position is the signal that opens the intrinsics evidence gate (CLAUDE.md) — that judgement is yours to make from where they land.
