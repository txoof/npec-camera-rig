# Figures for the metrology log

Images that show a result in `docs/metrology-log.md`, kept in git so the log and its evidence
travel together into reports and papers. Started 2026-10-23 (Aaron, #223); before that, the log
named files in `~/scratch`, which is not kept.

- **One folder per log section**, named by its number: `16.8/` holds the figures of section 16.8.
- **Every figure is linked from its section**, with a caption saying what it shows, how it was
  made (script and command, or "picked from" for photos and crops) and where the raw data is.
- **Small files.** Charts as PNG, about 100 to 200 KB at most; photos and crop sheets as JPG,
  scaled down to under about 1 MB. Full-size photos stay in the experiment folders, which are
  never copied here.
- **Added in the same change as the write-up** that uses them. A figure is not changed after its
  section is written; a newer result gets a new figure.
- **Figures copied in later** from `~/scratch` say so in their caption (the date copied and the
  file they came from).
